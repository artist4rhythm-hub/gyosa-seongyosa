「교사 선교사」 기능 안내

지혜빛 선교원 · 다니엘 아마츠의 모든 학사·행정·경비·소통을
한 곳에서 — 우리 학교의 온라인 교무실입니다.

교사 선교사는 두 기관의 선생님들이 함께 쓰는 통합 업무 시스템입니다. 로그인하면 홈 화면에서 오늘의 출근·수업·일정·생일과 처리할 일을 한눈에 보고, 왼쪽 메뉴(모바일은 ☰)로 아래 기능들을 오갑니다. 컴퓨터·폰·패드 어디서나 같은 계정으로 이어서 쓸 수 있어요.
🎓 학사
학생과 학사 운영의 기본
👥
학생관리
전체 명단·재학생·재적 통계·생일·연락처. 학부모 사이트 가입 코드도 여기서 발급해요.
✅
출석부
반별 출석 체크와 통계 — 휴학 기간은 자동으로 반영됩니다.
🧩
반편성
새 학년도 반 배정과 담임 지정.
📅
학사일정
연간 행사·학기·방학을 달력으로 — 구글 캘린더 구독을 걸어두면 개인 폰 캘린더에도 자동으로 떠요(교사용·학부모용 분리).
🗓
구글 캘린더
연동된 구글 캘린더를 시스템 안에서 바로 봅니다.
📜
증명서 발급
재학·재적 증명서를 양식에 맞춰 발급하고 발급 이력을 남깁니다.
💼 근무 · 행정
출퇴근부터 결재까지
⏰
출근부
출퇴근 기록을 달력으로 — 월별 통계가 자동 집계됩니다.
📇
교직원 명부
전 교직원 연락처·부서·직책을 한 곳에서.
⏱
근무시간
근무 통계와 예외(조퇴·외출 등) 입력.
✍️
전자결재
기안 올리고 결재선 따라 승인 — 서명은 한 번 등록하면 계속 쓰여요. 결재할 문서가 오면 홈에 배지로 알려줍니다.
🗂
시간표
시간표 틀 만들기부터 수업 배정까지, 완성되면 기관별로 게시 — 모든 선생님이 두 기관 시간표를 열람하고, 학부모 공유 링크도 만들 수 있어요.
💰 경비
신청부터 정산·환급까지
💳
경비 지급 요청서
일반 경비 지급 요청과 결재, 학기별 취합.
🐷
수행성 경비
교재·활동비를 학생별로 청구·반환 — 영수증 첨부, 학년별 합산, 전체 취합표(이미지·PDF), 입금·환급 확인까지. 학부모 안내 링크로 학부모가 직접 내역 확인과 환급 계좌 입력을 해요.
🎪
활동 경비
행사별 회비 걷기·지출 기록·회계 보고를 행사 단위로 관리.
💬 소통
교직원끼리, 그리고 가정과
✉️
쪽지함
교직원끼리 주고받는 쪽지 — 새 쪽지는 홈에 배지로 표시됩니다.
📌
게시판
자유 글과 댓글로 소통하는 교직원 게시판.
📨
가정통신문
통신문을 작성·발행하면 로그인 없이 열리는 공유 링크가 생겨요 — 카톡으로 보내면 학부모가 바로 봅니다. 계좌번호 복사 버튼, 인쇄(A4)도 지원.
👨‍👩‍👧 학부모 서비스
학부모 전용 사이트가 따로 있어요
학부모는 담임에게 받은 가입 코드로 자녀를 연결하고, 기관별 전용 사이트에서 가정통신문 · 학사일정 · 시간표 · 반별/전체 소통 게시판 · 경비 내역과 환급 계좌를 이용합니다. 게시판에는 고운 말 필터가 있어 안심할 수 있어요.
🛠
학부모 관리 관리자
반 단위 가입 코드 일괄 발급·인쇄, 게시판 관리(공지·고정·삭제), 금칙어, 바로가기 링크, 연결 현황.
⚙️ 관리 관리자 전용
🛡
관리자
교직원 계정·권한, 인사정보, 부서·새 학년도, 접속 보안, 활동 로그, 공유 링크 조회 기록.
💡 이런 것도 있어요

「교사 선교사」 앱으로 설치하기

설치라기보다 홈 화면에 담아두는 것이에요 — 1분이면 끝!
앱스토어 없이, 용량 부담 없이, 늘 최신 버전으로 열립니다.

🚀 시작 전, 이것부터!
설치는 사이트를 연 상태에서 합니다. 카카오톡으로 링크를 받았다면 꼭 브라우저(사파리·크롬)로 열어 주세요 — 카톡 안에서 바로 열면 설치 메뉴가 없어요.
🌐 교사 선교사 사이트 열기
🍎 아이폰 · 아이패드 (사파리)
1
사파리로 사이트를 엽니다
카톡에서 열렸다면: 오른쪽 아래 ··· → 기본 브라우저로 열기(또는 주소 복사 후 사파리에 붙여넣기)
2
아래(아이패드는 위) 공유 버튼 ⬆︎ 네모에 화살표를 누릅니다
3
목록을 아래로 내려 「홈 화면에 추가」를 누릅니다
안 보이면 목록 맨 아래 동작 편집에서 추가할 수 있어요
4
오른쪽 위 「추가」를 누르면 끝!
홈 화면에 교사 선교사 아이콘이 생깁니다 🎉
⚠️ 아이폰은 사파리에서만 홈 화면 추가가 됩니다. 크롬·카톡 안에서는 메뉴가 없어요.
🤖 안드로이드 폰 · 패드 (크롬)
1
크롬으로 사이트를 엽니다
카톡에서 열렸다면: 오른쪽 위 ⋮ → 다른 브라우저로 열기
2
오른쪽 위 ⋮ 메뉴를 누릅니다
3
「홈 화면에 추가」 또는 「앱 설치」를 누릅니다
기기에 따라 문구가 달라요 — 둘 다 같은 기능입니다. 주소창에 설치 안내 창이 저절로 뜨면 그걸 눌러도 돼요
4
「설치」/「추가」를 누르면 끝!
홈 화면(또는 앱 목록)에 교사 선교사가 생깁니다 🎉
💡 삼성 인터넷을 쓰신다면: 아래 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면
🪟 윈도우 컴퓨터 (크롬 · 엣지)
1
크롬(또는 엣지)으로 사이트를 엽니다
2
주소창 오른쪽 끝의 설치 아이콘 ⊕ 모니터에 ↓을 누릅니다
아이콘이 안 보이면: 오른쪽 위 ⋮ → 전송, 저장 및 공유 → 「교사 선교사 설치」
(엣지는 … → 앱 → 이 사이트를 앱으로 설치)
3
「설치」를 누르면 끝!
바탕화면·시작 메뉴에 아이콘이 생기고, 주소창 없는 앱 창으로 열립니다 🎉
작업 표시줄에 고정하려면: 실행 후 작업 표시줄 아이콘 우클릭 → 작업 표시줄에 고정
🍏 맥 컴퓨터 (크롬 또는 사파리)
방법 A — 크롬 (추천)
1
크롬으로 사이트를 엽니다
2
주소창 오른쪽 설치 아이콘 ⊕ 모니터에 ↓ → 「설치」
아이콘이 안 보이면: ⋮ → 전송, 저장 및 공유 → 「교사 선교사 설치」
3
끝! 런치패드·독에서 앱처럼 열립니다 🎉
독에 계속 두려면: 실행 후 독 아이콘 우클릭 → 옵션 → Dock에 유지
방법 B — 사파리
1
사파리로 사이트를 연 뒤, 메뉴 막대 파일 → 「Dock에 추가」
(또는 공유 버튼 ⬆︎ → Dock에 추가) → 추가를 누르면 끝!
❓ 자주 묻는 질문
Q. 설치하면 뭐가 좋아요?

홈 화면·바탕화면에서 한 번에 열리고, 주소창 없는 깔끔한 전체 화면으로 진짜 앱처럼 쓸 수 있어요. 로그인도 유지됩니다.

Q. 업데이트는 어떻게 하나요?

아무것도 안 하셔도 돼요 — 열 때마다 자동으로 최신 버전이 적용됩니다.

Q. 용량을 많이 차지하나요?

아니요, 일반 앱과 달리 거의 차지하지 않습니다. 앱스토어 설치가 아니라 바로가기에 가까워요.

Q. 화면이 하얗게/까맣게 멈춰요

15초 정도 기다리면 🧹 임시 저장 비우고 새로 열기 단추가 나타납니다 — 한 번 누르면 해결돼요. 그래도 안 되면 관리자(이현우 선생님)에게 알려주세요.

Q. 지워도 되나요?

네, 아이콘을 길게 눌러(컴퓨터는 우클릭) 삭제하면 됩니다. 자료는 서버에 있어서 아무 영향 없어요.

🎉 설치가 끝나면 교사 선교사 아이콘으로 접속해 로그인하세요.
궁금한 점은 행정실로 문의해 주세요!
